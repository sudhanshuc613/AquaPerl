🔹 SCENARIO A: TUMHAARE PAAS KOI PURANA REPO NAHI HAI (NAYA UPLOAD)
═══════════════════════════════════════════════════════════════════

1) Pehle ZIP ko unzip karo kisi folder me (e.g., C:\ro-patna\)
   - Is folder me directly src/, prisma/, package.json, vercel.json
     dikhna chahiye.

2) GitHub pe jao → New Repository → naam do "ro-patna" → Public
   → "Create repository" → waha ek URL milega, jaise:
   https://github.com/tumhareusername/ro-patna.git

3) CMD khol ke unzip wale folder me jao:

    cd C:\ro-patna

4) Ye commands EK EK KARKE chalao (sab copy paste kar sakte ho):

    git init

5) Push karte waqt GitHub login maangega:
   - Browser me GitHub login khulega → authorize kar do.
   - Ya GitHub ke Settings → Developer Settings → Personal access tokens
     se token bana ke password ki jagah use karo.

6) Done! 30-60 second me saari files GitHub pe pahunch jayengi.
   Phir Vercel pe ja ke import kar lo.

🔹 AGAR ERROR AAYE TO:
═══════════════════════════════════════════════════════════════════

❌ "fatal: not a git repository"
   → Tum galat folder me ho. `cd` se us folder me jao jaha package.json hai.

❌ "remote origin already exists"
   → Ye chalao:
       git remote remove origin
       git remote add origin https://github.com/TUMHARA_USERNAME/ro-patna.git

❌ "Authentication failed"
   → GitHub ka Personal Access Token (PAT) banao:
     GitHub → Settings → Developer settings → Personal access tokens →
     Tokens (classic) → Generate new token → repo scope check → Generate.
     Token ko copy karke password ki jagah paste karo.

❌ "rejected / non-fast-forward"
   → Ye chalao:
       git pull origin main --rebase
       git push -u origin main

❌ "Filename too long" (Windows kabhi kabhi deta hai):
   → Ye pehle chalao:
       git config --system core.longpaths true

❌ Push me 403 / permission denied:
   → Repo ke URL me sahi username hai check karo, ya GitHub desktop app
     use kar lo (asaan hai): https://desktop.github.com/

   - Ya direct: https://vercel.com/dashboard → "Add New..." → "Project"
     → neeche "Clone Template" ke jagah "Deploy" ke upar ek dropzone hoga
     jaha folder directly drag-drop kar sakte ho.
3. RO-PATNA-ADVANCED-FINAL.zip ko unzip karo → poora folder Vercel pe
   drag karke chhod do.
4. Environment Variables daalo (DATABASE_URL, NEXTAUTH_SECRET, NEXTAUTH_URL).
5. Deploy button dabao — ho gaya!
