─────────────────────────────────────────────────────────────────
🔹 STEP 2: ZIP KO UNZIP KARO AUR GITHUB PE UPLOAD KARO
─────────────────────────────────────────────────────────────────
1. RO-PATNA-ADVANCED-FINAL.zip ko kisi folder me unzip karo (Right click → Extract All)
2. GitHub repo wale page pe jao (jo Step 1 me banaya tha / ya purana repo)
3. "Add file" button (top right) → "Upload files"
4. Ab unzip kiye hue folder me jao → SARE FILES SELECT KARO (Ctrl+A)
   ⚠️  Important: andar ka poora content upload karo (src/, prisma/, public/,
   package.json, vercel.json, next.config.mjs — yeh sab root me dikhna chahiye)

      folder ban jayega to Vercel ko code nahi milega)
5. Neeche "Commit changes" button dabao (title me likh do: "final deploy")
6. 30-60 seconds me saari files upload ho jayengi

1. https://vercel.com/signup → "Continue with GitHub" se sign up karo (FREE)
2. Signup ke baad dashboard pe "Add New..." → "Project" click karo
3. "Import Git Repository" me tumhara "ro-patna" repo dikhega → uska "Import" button dabao
4. Ab ek form aayega — BAS 3 CHEEZ FILL KARO BAAKI SAB CHHOD DO:

   📝 Environment Variables section me yeh 3 daalo:

   ┌─────────────────────┬────────────────────────────────────────┐
   │ NAME                │ VALUE                                  │
   ├─────────────────────┼────────────────────────────────────────┤
   │ DATABASE_URL        │ Neon DB wali pichhli wali URL daalo    │
   │                     │ (postgresql://....neon.tech/...)       │
   ├─────────────────────┼────────────────────────────────────────┤
   │ NEXTAUTH_SECRET     │ Koi bhi random long string daalo       │
   │                     │ Example: ropatna-2026-secret-key-x9k2m │
   ├─────────────────────┼────────────────────────────────────────┤
   │ NEXTAUTH_URL        │ Deploy ke baad jo URL mile usko yaha   │
   │                     │ daalna (pehle deploy to ho jaye, phir  │
   │                     │ Settings me baad me badal sakte ho)    │
   └─────────────────────┴────────────────────────────────────────┘

   💡 Tip: NEXTAUTH_SECRET ke liye yeh use kar lo (as-is):

AGAR KOI ERROR AAYE TO?
═══════════════════════════════════════════════════════════════════

❌ "Build failed" Vercel pe?
   → Vercel ke Deployments me jao → latest deploy pe click → "Build Logs"
     me jo RED error hai woh mujhe WhatsApp/screenshot bhejo.

❌ "Login nahi ho raha"?
   → Apne domain pe /api/setup-admin kholo (ek naya tab me), woh automatically
     admin user bana dega. Phir admin@roserviceinpatna.in / admin@123 se login.

❌ "Phone number change nahi ho raha"?
   → Admin → Settings me jao, sahi number daalo, Save dabao, 1 minute wait,
     Ctrl+F5 karo (hard refresh).

❌ "Map nahi dikh raha"?
   → Ad blocker ya Brave browser Google Maps block karta hai — Chrome /
     Firefox normal mode me dekh lo.

❌ "Site bahut slow hai"?
   → Impossible — Next.js static site hai, sub-second load hoga. Agar slow
     lag raha hai to internet check karo.
