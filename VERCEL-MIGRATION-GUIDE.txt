🚀 STEP-BY-STEP MIGRATION (30 minute ka kaam)
================================================================

---
STEP 0: Pehle naye Vercel account ki tyari
---
1. Chrome mein ek Incognito window kholo (purane Vercel account se
   logout rehna chahiye).
2. https://vercel.com/signup par jao.

4. Signup complete karo (email verify karo agar puche).
5. Dashboard pe "Add New..." → "Project" dikhega. Abhi mat banao,

STEP 1: Pehle PURANE Vercel se environment variables copy kar lo
---
Purane Vercel account mein login raho:
1. https://vercel.com/dashboard pe jao
2. Apna AquaPerl project select karo
3. Left menu → Settings → Environment Variables
4. Wahan saari variables ek kaghaz/Notepad mein note kar lo, ya
   screenshot le lo. Ye rahi list (exact values chahiye):

   ──────────────────────────   ────────────────────────────────

   NEXTAUTH_SECRET              aquanexa-top-secret-key-2026...
   NEXTAUTH_URL                 https://www.roserviceinpatna.in
   ADMIN_EMAIL                  admin@roserviceinpatna.in
   NEXT_PUBLIC_SITE_URL         https://www.roserviceinpatna.in

   STRIPE_SECRET_KEY
   STRIPE_PUBLISHABLE_KEY
   TWILIO_ACCOUNT_SID
   TWILIO_AUTH_TOKEN

   SMTP_HOST

   chahiye, "Preview" nahi, "Secret" nahi — yeh galti mat karna.

STEP 4: Naye project mein DOMAIN add karo (DNS change se PEHLE)
---

Naye Vercel project mein:

2. "Add Domain" par click karo.
3. Pehla domain daalo: www.roserviceinpatna.in

     Name: www

4. Phir "Add Domain" par click karke second domain daalo:
   roserviceinpatna.in (bare, no-www)

STEP 6: DNS SWITCH (yahi se real migration hoga — 5 minute downtime max)
---
Ab actual DNS change karna hai. Pehle decide karo DNS kahan hai:
Usually 3 locations mein se ek hota hai:
- Godaddy (domain wahi se khareeda)
- Namecheap
- Cloudflare (agar tumne pehle shift kiya ho)

👉 Apne domain registrar/Godaddy/Cloudflare mein login karo,
DNS management mein jao, aur OLDE Vercel ke records ko HATA KE
naye Vercel ke records lagao:

A. PURANE VERCEL DNS RECORDS HATAO (jo ab kaam nahi karenge):
   - Purane A-record (76.76.21.21 wale rehne do — Vercel ka same IP
     hai to chalta rahega, lekin safest hai delete karke naye
     lagana)
   - Purane CNAME record (jo cname.vercel-dns.com ki jagah kuch aur
     ho ya purane verification ke ho)
   - Baki ke vercel verification TXT records hatane ki zaroorat
     nahi, rehne do.

B. NAYE VERCEL KE RECORDS LAGAO (Step 4 mein jo note kiye the):

   Record 1 (www subdomain)
   ──────────────────────
   Type:     CNAME
   Name:     www
   Value:    cname.vercel-dns.com
   TTL:      300 (5 minute — jaldi propagate ke liye)

   Record 2 (apex/root domain — non-www)
   ──────────────────────────────────────
   Type:     A
   Name:     @ (ya blank, ya root)
   Value:    76.76.21.21
   TTL:      300

   ⚠️  Cloudflare use kar rahe ho to Proxy status "DNS only"
   (grey cloud) rakho initially, naye Vercel ke SSL banne tak
   (10-15 minute). Baad mein orange proxy kar sakte ho.

C. Save karo. DNS propagation shuru ho jayega. Usually 2-5 minute
   mein ho jata hai, kabhi kabhi 30 min lagta hai.

================================================================
⚠️  KYA-KYA GALTI HO SAKTI HAI (BACHNA)
================================================================

1. Environment variable miss/galat
   → Deploy fail hoga ya 500 error ayega. Double-check karo sab
     vars.

2. NEXT_PUBLIC_SITE_URL galat / Secret bana diya
   → Sitemap/canonical mein wrong URL jayega, SEO kharab hoga.
     NEXT_PUBLIC_ prefix wale variables ko Vercel pe "Encrypted"
     nahi, "Plain text" rakhna padta hai (publicly browser mein
     jate hain) — Production environment select karo, Secret mat
     banao.

3. Node version 24.x set nahi kiya
   → Build fail hoga (purana error wapas aa jayega). Naye project
   mein Settings → Functions → Node.js Version 24.x set karo.

4. DNS par purane records nahi hataye
   → Conflict ho sakta hai. Purane Vercel wale records jinke
     values alag hon unko hata do.

5. Non-www ka A-record galat lagaya
   → Non-www kaam nahi karega. 76.76.21.21 Vercel ka fixed IP hai.

6. Cloudflare orange cloud (proxy) on kar diya deploy ke pehle
   → SSL issue aa sakta hai. Pehle grey cloud (DNS only) rakho
   15 minute, phir orange kar lo.

7. Admin email/password bhool jane ki tenson nahi — same Neon DB
   hai, wohi credentials kaam karenge. Backup ke liye naye project
   mein ek baar /api/setup-admin pe chala jaana (seed ho jayega).

🔒 RANKING KYUN NAHI GIREGI?
================================================================
- Domain wahi hai (www.roserviceinpatna.in) → Google isko same
  samajhta hai
- Content bilkul same hai (same repo, same meta, same pages)
- Sitemap/canonical/meta/schema same URLs pe same content
- Redirects (non-www→www) same lag rahe hain
- Server location bhi Mumbai (bom1) — speed same rahegi
- HTML verification file / meta tag dono present (GSC verified
  rahega)

Google ko kabhi pata bhi nahi chalega ki server badla hai. Ranking
bilkul waisi hi rahegi, aur future deployments bhi same tarah se
honge (GitHub push → Vercel auto deploy).

================================================================
💡 AGAR PURANE VERCEL ACCOUNT MEIN CUSTOM DOMAIN ADD HUA HAI TO?
================================================================
Important note: Ek domain ek hi Vercel account se connected reh
sakta hai. Isliye jab tum naye project mein domain add karoge to
Vercel automatically purane project se domain ko detach karne
ke liye kah sakta hai, ya verification ke liye ek extra TXT record
de sakta hai. Us case mein:
1. Vercel ka diya TXT record DNS mein add karo
2. Ya purane project mein jaake Settings → Domains → www ko remove
   karo
3. Phir naye project mein re-add karo
(Don't worry — jab tak DNS pe CNAME/A record correct hai, site
chalta rahega. Domain ownership verify hone mein 2 minute lagte
hain.)
